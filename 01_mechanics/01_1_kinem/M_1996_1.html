ניסוח השאלה המלא (סטנדרט בחינת בגרות)

ברגע $t = 0$ גוף מתחיל לנוע ימינה, לאורך קו ישר. הגרף הנתון מתאר את מהירות הגוף כפונקציה של הזמן מ-$t = 0$ ועד $t = 25.0\text{ s}$.
הכיוון ימינה מוגדר כחיובי.

נתוני המערכת ושלבי התנועה:
  • ברגע $t = 0$: הגוף מתחיל לנוע ממנוחה ימינה מנקודת המוצא ($v_0 = 0$, $x_0 = 0$).
  • קטע 1 ($0 < t < 5.0\text{ s}$): עלייה ליניארית במהירות מ-$0$ ל-$10.0\text{ m/s}$.
  • קטע 2 ($5.0\text{ s} < t < 8.0\text{ s}$): מהירות קבועה של $10.0\text{ m/s}$ ימינה.
  • קטע 3 ($8.0\text{ s} < t < 20.0\text{ s}$): ירידה ליניארית מ-$10.0\text{ m/s}$ ל-$-5.0\text{ m/s}$ (איפוס מהירות ב-$t = 16.0\text{ s}$).
  • קטע 4 ($20.0\text{ s} < t < 25.0\text{ s}$): עלייה ליניארית מ-$-5.0\text{ m/s}$ עד לעצירה ב-$v = 0$ ברגע $t = 25.0\text{ s}$.
תרשים: גרף מהירות-זמן $v(t)$ של הגוף

סעיף א': בדיקת שינוי כיוון התנועה

נתוני הגרף:
  • הכיוון החיובי מוגדר ימינה.
  • בפרק הזמן $0 \le t < 16.0\text{ s}$: המהירות $v(t) > 0$.
  • ברגע $t = 16.0\text{ s}$: המהירות מתאפסת ($v = 0$).
  • בפרק הזמן $16.0\text{ s} < t < 25.0\text{ s}$: המהירות $v(t) < 0$.
השאלה הנשאלת:

האם הגוף משנה את כיוון תנועתו? אם לא – נמק. אם כן – ציין מתי, ונמק.

קביעה:

כן, הגוף משנה את כיוון תנועתו ברגע $t = 16.0\text{ s}$.

נימוק פיזיקלי:

כיוון תנועתו של גוף בתנועה חד-ממדית נקבע ישירות ובלעדית על-פי סימן המהירות הרגעית שלו (ולא על פי סימן התאוצה):

  • בפרק הזמן $0 \le t < 16.0\text{ s}$, מהירות הגוף חיובית ($v > 0$), ולכן הגוף נע ימינה.
  • ברגע $t = 16.0\text{ s}$, הגרף חוצה את ציר הזמן והמהירות מתאפסת רגעית ($v = 0$).
  • החל מרגע $t = 16.0\text{ s}$ ועד $t = 25.0\text{ s}$, מהירות הגוף שלילית ($v < 0$), ולכן הגוף נע שמאלה.

מכיוון שהמהירות משנה את סימנה מחיובי לשלילי, הגוף משנה את כיוון תנועתו מימינה לשמאלה בדיוק ברגע זה.

✓
הגוף משנה את כיוון תנועתו ברגע $t = 16.0\text{ s}$, מכיוון שברגע זה מהירות הגוף משנה את סימנה מערך חיובי (תנועה ימינה) לערך שלילי (תנועה שמאלה).

סעיף ב': סרטוט גרף תאוצת הגוף כפונקציה של הזמן $a(t)$

חישוב שיפועי הגרף $v(t)$:
  • תאוצת הגוף היא נגזרת המהירות לפי הזמן (שיפוע הגרף): $a = \frac{\Delta v}{\Delta t}$.
  • בכל אחד מארבעת הקטעים, הגרף הוא קו ישר, ולכן התאוצה בכל קטע היא קבועה.
השאלה הנשאלת:

סרטט גרף המתאר את תאוצת הגוף כפונקציה של הזמן מרגע $t = 0$ עד רגע $t = 25.0\text{ s}$.

נוסחאות דף עזר:
$a = \frac{\Delta v}{\Delta t} = \frac{v_2 - v_1}{t_2 - t_1}$
חישוב התאוצה בכל פרק זמן:

1. קטע א' ($0 < t < 5.0\text{ s}$):

$$a_1 = \frac{10.0 - 0}{5.0 - 0} = +2.0\text{ m/s}^2$$

2. קטע ב' ($5.0\text{ s} < t < 8.0\text{ s}$): מהירות קבועה של $10.0\text{ m/s}$:

$$a_2 = \frac{10.0 - 10.0}{8.0 - 5.0} = 0\text{ m/s}^2$$

3. קטע ג' ($8.0\text{ s} < t < 20.0\text{ s}$): ירידה מ-$10.0\text{ m/s}$ ל-$-5.0\text{ m/s}$:

$$a_3 = \frac{-5.0 - 10.0}{20.0 - 8.0} = \frac{-15.0}{12.0} = -1.25\text{ m/s}^2$$

4. קטע ד' ($20.0\text{ s} < t < 25.0\text{ s}$): עלייה מ-$-5.0\text{ m/s}$ ל-$0$:

$$a_4 = \frac{0 - (-5.0)}{25.0 - 20.0} = \frac{5.0}{5.0} = +1.0\text{ m/s}^2$$
גרף תאוצה כפונקציה של הזמן $a(t)$
✓
הגרף הוא גרף מדרגות אופקיות קבועות:
$a = +2.0\text{ m/s}^2$ ב-$[0, 5\text{ s}]$, $a = 0$ ב-$[5\text{ s}, 8\text{ s}]$, $a = -1.25\text{ m/s}^2$ ב-$[8\text{ s}, 20\text{ s}]$, ו-$a = +1.0\text{ m/s}^2$ ב-$[20\text{ s}, 25\text{ s}]$.

סעיף ג': בדיקת חזרת הגוף לנקודת המוצא

משמעות גאומטרית של העתק:
  • ההעתק שווה לשטח הכלוא בין עקומת המהירות לציר הזמן: $\Delta x = \int v\,dt$.
  • שטח מעל ציר הזמן מייצג העתק חיובי ימינה ($S_+$).
  • שטח מתחת לציר הזמן מייצג העתק שלילי שמאלה ($S_-$).
  • כדי לחזור לנקודת המוצא ($x = 0$), נדרש שההעתק הכולל יתאפס ($\Delta x_{\text{total}} = 0$).
השאלה הנשאלת:

האם במהלך תנועתו הגוף חוזר לנקודת המוצא (הנקודה שממנה יצא ברגע $t = 0$)? אם כן – באיזה רגע; אם לא – נמק.

קביעה:

לא, הגוף אינו חוזר לנקודת המוצא בשום שלב במהלך תנועתו.

חישוב ההעתקים המפורט:

1. ההעתק ימינה (מ-$t = 0$ ועד $t = 16.0\text{ s}$): שטח טרפז מעל ציר הזמן:

$$\Delta x_{\text{right}} = S_{\text{trapezoid}} = \frac{(16.0 - 0) + (8.0 - 5.0)}{2} \cdot 10.0 = \frac{16.0 + 3.0}{2} \cdot 10.0 = 19.0 \cdot 5.0 = 95.0\text{ m}$$

כלומר, ב-$16.0$ השניות הראשונות הגוף התרחק $95.0\text{ m}$ ימינה מנקודת המוצא.

2. ההעתק שמאלה (מ-$t = 16.0\text{ s}$ ועד $t = 25.0\text{ s}$): שטח משולש מתחת לציר הזמן:

$$\Delta x_{\text{left}} = -S_{\text{triangle}} = -\frac{(25.0 - 16.0) \cdot 5.0}{2} = -\frac{9.0 \cdot 5.0}{2} = -22.5\text{ m}$$

כלומר, בכל שלב חזרתו שמאלה הגוף עבר מרחק של $22.5\text{ m}$ בלבד.

3. מיקומו הסופי של הגוף בסוף התנועה ($t = 25.0\text{ s}$):

$$x(25.0) = x_0 + \Delta x_{\text{right}} + \Delta x_{\text{left}} = 0 + 95.0 - 22.5 = +72.5\text{ m}$$

הגוף נעצר במרחק $72.5\text{ m}$ מימין לנקודת המוצא. מכיוון ששטח הגרף מעל הציר ($95.0\text{ m}$) גדול בהרבה משטח הגרף מתחת לציר ($22.5\text{ m}$), הגוף לא חזר לנקודת המוצא.

✓
הגוף אינו חוזר לנקודת המוצא. נימוק: ב-16 השניות הראשונות נע הגוף ימינה מרחק של $95.0\text{ m}$, וב-9 השניות הבאות נע שמאלה מרחק של $22.5\text{ m}$ בלבד, כך שבסיום התנועה הוא נמצא ב-$x = +72.5\text{ m}$.

סעיפים ד'-ה': השלמת טבלת וקטורי התנועה (מהירות, תאוצה וכוח שקול)

כללי חלוקת הזמנים:
  • בכל פעם שכיוונו של אחד הווקטורים (מהירות, תאוצה או כוח שקול) משתנה, מתחיל פרק זמן חדש.
  • לפי החוק השני של ניוטון ($\Sigma \vec{F} = m\vec{a}$), כיוון הכוח השקול זהה תמיד לכיוון התאוצה. כאשר $a = 0$, גם $\Sigma F = 0$.
  • שינוי כיוון המהירות חל ב-$t = 16.0\text{ s}$, ולכן הקטע שבין $8\text{ s}$ ל-$20\text{ s}$ מתפצל לשני תת-קטעים.
השאלה הנשאלת:

העתק את הטבלה למחברתך, השלם את השורה הראשונה (סעיף ד'), ולאחר מכן השלם את יתר השורות עבור פרקי הזמן $5.0\text{ s} < t < 25.0\text{ s}$ (סעיף ה').

הטבלה המלאה:
פרק הזמן כיוון המהירות ($\vec{v}$) כיוון התאוצה ($\vec{a}$) כיוון הכוח השקול ($\Sigma \vec{F}$)
$0 < t < 5.0\text{ s}$ (סעיף ד') ימינה ($v > 0$) ימינה ($a = +2.0\text{ m/s}^2$) ימינה
$5.0\text{ s} < t < 8.0\text{ s}$ ימינה ($v = 10.0\text{ m/s}$) אפס ($a = 0$) אפס
$8.0\text{ s} < t < 16.0\text{ s}$ ימינה ($v > 0$) שמאלה ($a = -1.25\text{ m/s}^2$) שמאלה
$16.0\text{ s} < t < 20.0\text{ s}$ שמאלה ($v < 0$) שמאלה ($a = -1.25\text{ m/s}^2$) שמאלה
$20.0\text{ s} < t < 25.0\text{ s}$ שמאלה ($v < 0$) ימינה ($a = +1.0\text{ m/s}^2$) ימינה
הסבר פיזיקלי מפורט לחלוקה:
  • ב-$0 < t < 5.0\text{ s}$ (סעיף ד'): המהירות גדלה ימינה, ולכן התאוצה והכוח השקול פועלים ימינה (תנועה מואצת).
  • ב-$5.0\text{ s} < t < 8.0\text{ s}$ (סעיף ה'): המהירות קבועה ימינה, לכן שיפוע הגרף מתאפס ($a = 0$), ובהתאם לחוק הראשון/השני של ניוטון שקול הכוחות שווה לאפס.
  • פיצול הקטע $8.0\text{ s} < t < 20.0\text{ s}$ לשניים: לאורך כל הקטע התאוצה והכוח השקול קבועים ומכוונים שמאלה ($a = -1.25\text{ m/s}^2$). אולם, ברגע $t = 16.0\text{ s}$ המהירות מתאפסת והופכת מימינה לשמאלה. לכן חובה לפצל: עד $16.0\text{ s}$ המהירות ימינה (תנועה מואטת), ומ-$16.0\text{ s}$ עד $20.0\text{ s}$ המהירות שמאלה (תנועה מואצת שמאלה).
  • ב-$20.0\text{ s} < t < 25.0\text{ s}$ (סעיף ה'): המהירות ממשיכה להיות שמאלה ($v < 0$), אך גודלה קטן (בלימה לקראת עצירה), ולכן התאוצה והכוח השקול פועלים ימינה ($a = +1.0\text{ m/s}^2$).
✓
הטבלה הושלמה במלואה בהתאם לחוקי ניוטון וסימני המהירות והתאוצה בכל חמשת פרקי הזמן.

סעיף ו': חישוב תאוצת הגוף ברגע $t = 16.0\text{ s}$

נתוני הרגע $t = 16.0\text{ s}$:
  • ברגע זה המהירות הרגעית של הגוף מתאפסת: $v(16) = 0$.
  • הרגע $t = 16.0\text{ s}$ נמצא עמוק בתוך קטע ישר רציף מ-$t = 8.0\text{ s}$ עד $t = 20.0\text{ s}$.
השאלה הנשאלת:

מהי תאוצת הגוף ברגע $t = 16.0\text{ s}$? נמק.

קביעה וחישוב:

תאוצת הגוף ברגע $t = 16.0\text{ s}$ היא $-1.25\text{ m/s}^2$ (גודלה $1.25\text{ m/s}^2$ וכיוונה שמאלה).

$$a(16.0) = \frac{\Delta v}{\Delta t} = \frac{-5.0\text{ m/s} - 10.0\text{ m/s}}{20.0\text{ s} - 8.0\text{ s}} = \frac{-15.0}{12.0} = -1.25\text{ m/s}^2$$
נימוק פיזיקלי (הבהרת תפיסה שגויה נפוצה):

תלמידים רבים טועים לחשוב שמכיוון שמהירות הגוף ברגע זה היא אפס ($v = 0$), גם תאוצתו חייבת להיות אפס. זוהי שגיאה מושגית יסודית!
תאוצה אינה מהירות, אלא קצב השינוי של המהירות בזמן ($\vec{a} = \frac{d\vec{v}}{dt}$).
בגרף מהירות-זמן, התאוצה מיוצגת על ידי שיפוע הגרף. לאורך כל פרק הזמן מ-$t = 8.0\text{ s}$ ועד $t = 20.0\text{ s}$, הגרף הוא קו ישר רציף ואחיד בעל שיפוע קבוע של $-1.25\text{ m/s}^2$.
לכן, בכל נקודה ונקודה בקטע זה – כולל ברגע המעבר דרך האפס ב-$t = 16.0\text{ s}$ – קצב שינוי המהירות קיים, קבוע ושווה בדיוק ל-$-1.25\text{ m/s}^2$. (בדומה לגוף הנזרק אנכית ומגיע לשיא הגובה: מהירותו מתאפסת רגעית, אך תאוצת הכובד ממשיכה לפעול כסדרה: $a = -g$).

✓
תאוצת הגוף ברגע $t = 16.0\text{ s}$ היא $-1.25\text{ m/s}^2$ (גודלה $1.25\text{ m/s}^2$ וכיוונה שמאלה), על-פי שיפוע הגרף באותו רגע.
