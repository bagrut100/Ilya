ניסוח השאלה המלא (סטנדרט בחינת בגרות)

שני תלמידים התחרו במרוץ מכוניות לאורך מסלול ישר בלונה פארק.
שתי המכוניות, א' ו-ב', החלו את תנועתן ממנוחה ($v_0 = 0$), מאותו מקום ($x_0 = 0$), באותו זמן ($t = 0$) ובאותו כיוון לאורך מסלול ישר.
מכונית א' חצתה את קו הסיום לאחר $60.00\text{ s}$.
גרף א' מתאר את מהירות מכונית א' כפונקציה של הזמן במהלך תנועתה מההתחלה עד קו הסיום.
גרף ב' מתאר את מהירות מכונית ב' כפונקציה של הזמן במהלך $30.00$ השניות הראשונות לתנועתה.
מכונית ב' המשיכה לנוע לאחר $t = 30.00\text{ s}$ לכיוון קו הסיום, וחצתה את קו הסיום $2.00\text{ s}$ לפני מכונית א' (כלומר ברגע $t = 58.00\text{ s}$).

נתוני המערכת מתוך הגרפים:
  • מכונית א': 0–10s: תאוצה קבועה מ-0 ל-$6.00\text{ m/s}$; 10–50s: תאוצה קבועה מ-$6.00\text{ m/s}$ ל-$10.00\text{ m/s}$; 50–60s: מהירות קבועה של $10.00\text{ m/s}$ עד לקו הסיום ($t = 60.00\text{ s}$).
  • מכונית ב': 0–10s: תאוצה קבועה מ-0 ל-$2.00\text{ m/s}$; 10–30s: תאוצה קבועה מ-$2.00\text{ m/s}$ ל-$10.00\text{ m/s}$; 30–58s: תנועה בתאוצה קבועה עד קו הסיום ($t = 58.00\text{ s}$).
תרשים: גרפי מהירות-זמן של מכונית א' (כחול) ומכונית ב' (אדום)

סעיף א': סרטוט גרף תאוצת מכונית א' כפונקציה של הזמן $a(t)$

קטעי התנועה של מכונית א':
  • קטע 1 ($0 \le t < 10.00\text{ s}$): עלייה ליניארית מ-$v = 0$ ל-$v = 6.00\text{ m/s}$.
  • קטע 2 ($10.00\text{ s} < t < 50.00\text{ s}$): עלייה ליניארית מ-$v = 6.00\text{ m/s}$ ל-$v = 10.00\text{ m/s}$.
  • קטע 3 ($50.00\text{ s} < t \le 60.00\text{ s}$): מהירות קבועה של $v = 10.00\text{ m/s}$.
השאלה הנשאלת:

סרטט גרף של תאוצת מכונית א' כפונקציה של הזמן, מתחילת תנועתה ($t = 0$) עד שהגיעה לקו הסיום ($t = 60.00\text{ s}$).

נוסחאות דף עזר:
$a = \frac{\Delta v}{\Delta t} = \frac{v_2 - v_1}{t_2 - t_1}$ (שיפוע הגרף)
1. חישוב התאוצה בכל אחד מפרקי הזמן:

קטע 1 ($0 \le t < 10.00\text{ s}$):

$$a_1 = \frac{6.00 - 0}{10.00 - 0} = \frac{6.00}{10.00} = 0.60\text{ m/s}^2$$

קטע 2 ($10.00\text{ s} < t < 50.00\text{ s}$):

$$a_2 = \frac{10.00 - 6.00}{50.00 - 10.00} = \frac{4.00}{40.00} = 0.10\text{ m/s}^2$$

קטע 3 ($50.00\text{ s} < t \le 60.00\text{ s}$): תנועה קצובה (קו אופקי):

$$a_3 = \frac{10.00 - 10.00}{60.00 - 50.00} = 0\text{ m/s}^2$$
גרף תאוצת מכונית א' כפונקציה של הזמן $a(t)$
✓
הגרף הוא גרף מדרגות אופקיות: $0.60\text{ m/s}^2$ בין $0$ ל-$10\text{ s}$, $0.10\text{ m/s}^2$ בין $10\text{ s}$ ל-$50\text{ s}$, ו-$0\text{ m/s}^2$ בין $50\text{ s}$ ל-$60\text{ s}$.

סעיף ב': חישוב המרחק שעברה מכונית א' עד לקו הסיום (אורך המסלול)

משמעות גאומטרית של העתק:
  • ההעתק שווה לשטח הכלוא מתחת לגרף מהירות-זמן $v(t)$: $\Delta x = \int v(t)\,dt$.
  • ניתן לחלק את השטח מתחת לגרף א' לשלושה מצולעים פשוטים: משולש ישר-זווית, טרפז ישר-זווית ומלבן.
  • משך התנועה הכולל של מכונית א': $\Delta t = 60.00\text{ s}$.
השאלה הנשאלת:

חשב את המרחק שעברה מכונית א' מתחילת תנועתה עד שהגיעה לקו הסיום.

נוסחאות דף עזר:
$\Delta x = S_{\text{triangle}} + S_{\text{trapezoid}} + S_{\text{rectangle}}$
חישוב השטח מתחת לגרף א' לפי קטעים:

1. שטח קטע ראשון ($0 \le t \le 10.00\text{ s}$): משולש ישר-זווית

$$S_1 = \frac{\text{בסיס} \cdot \text{גובה}}{2} = \frac{10.00\text{ s} \cdot 6.00\text{ m/s}}{2} = 30.00\text{ m}$$

2. שטח קטע שני ($10.00\text{ s} \le t \le 50.00\text{ s}$): טרפז ישר-זווית

$$S_2 = \frac{v(10) + v(50)}{2} \cdot \Delta t_2 = \frac{6.00 + 10.00}{2} \cdot (50.00 - 10.00) = \frac{16.00}{2} \cdot 40.00 = 8.00 \cdot 40.00 = 320.00\text{ m}$$

3. שטח קטע שלישי ($50.00\text{ s} \le t \le 60.00\text{ s}$): מלבן

$$S_3 = v \cdot \Delta t_3 = 10.00\text{ m/s} \cdot (60.00 - 50.00)\text{ s} = 10.00 \cdot 10.00 = 100.00\text{ m}$$

סך כל המרחק (אורך מסלול המרוץ $L$):

$$L = \Delta x_A = S_1 + S_2 + S_3 = 30.00\text{ m} + 320.00\text{ m} + 100.00\text{ m} = 450.00\text{ m}$$
✓
המרחק שעברה מכונית א' עד לקו הסיום (אורך המסלול כולו) הוא $450.00\text{ מטרים}$.

סעיף ג': חישוב המרחק שעברה כל מכונית ב-$30$ השניות הראשונות

נתונים ברגע $t = 30.00\text{ s}$:
  • מכונית א': ב-$t = 10\text{ s}$ מהירותה $6.00\text{ m/s}$. מ-$10\text{ s}$ ל-$30\text{ s}$ התאוצה היא $0.10\text{ m/s}^2$.
  • מהירות מכונית א' ב-$t = 30\text{ s}$: $v_A(30) = 6.00 + 0.10 \cdot 20 = 8.00\text{ m/s}$.
  • מכונית ב': משולש ב-$[0, 10\text{ s}]$ עד ל-$2.00\text{ m/s}$, וטרפז ב-$[10\text{ s}, 30\text{ s}]$ מ-$2.00\text{ m/s}$ ל-$10.00\text{ m/s}$.
השאלה הנשאלת:

חשב את המרחק שעברה כל אחת מהמכוניות ב-30 השניות הראשונות לתנועתה ($0 \le t \le 30.00\text{ s}$).

נוסחאות דף עזר:
$\Delta x = \text{שטח מתחת לגרף } v(t)$
1. מרחק מכונית א' ב-30 השניות הראשונות ($x_A(30)$):

מורכב משטח המשולש ב-$[0, 10\text{ s}]$ ועוד שטח הטרפז ב-$[10\text{ s}, 30\text{ s}]$:

$$x_A(10) = 30.00\text{ m}$$ $$x_A(10 \to 30) = \frac{v_A(10) + v_A(30)}{2} \cdot (30.00 - 10.00) = \frac{6.00 + 8.00}{2} \cdot 20.00 = 7.00 \cdot 20.00 = 140.00\text{ m}$$ $$x_A(30) = 30.00\text{ m} + 140.00\text{ m} = 170.00\text{ m}$$
2. מרחק מכונית ב' ב-30 השניות הראשונות ($x_B(30)$):

נחשב את השטח מתחת לגרף ב' מ-$t = 0$ ועד $t = 30.00\text{ s}$:

  • קטע ראשון ($0 \le t \le 10.00\text{ s}$): משולש ישר-זווית מבסיס $10\text{ s}$ וגובה $2.00\text{ m/s}$:
    $$S_{B1} = \frac{10.00 \cdot 2.00}{2} = 10.00\text{ m}$$
  • קטע שני ($10.00\text{ s} \le t \le 30.00\text{ s}$): טרפז מבסיסים $2.00\text{ m/s}$ ו-$10.00\text{ m/s}$ וגובה $20.00\text{ s}$:
    $$S_{B2} = \frac{2.00 + 10.00}{2} \cdot (30.00 - 10.00) = \frac{12.00}{2} \cdot 20.00 = 6.00 \cdot 20.00 = 120.00\text{ m}$$

סך המרחק שעברה מכונית ב':

$$x_B(30) = S_{B1} + S_{B2} = 10.00\text{ m} + 120.00\text{ m} = 130.00\text{ m}$$
✓
ב-30 השניות הראשונות:
מכונית א' עברה $170.00\text{ מטרים}$.
מכונית ב' עברה $130.00\text{ מטרים}$.

סעיף ד': האם התרחש מפגש (שוויון מרחקים מנקודת המוצא) במהלך המרוץ?

השוואת מיקומי המכוניות בנקודות מפתח:
  • ברגע $t = 0$: שתיהן באותו מקום ($x_A = x_B = 0$).
  • ברגע $t = 30.00\text{ s}$: $x_A(30) = 170.00\text{ m}$ לעומת $x_B(30) = 130.00\text{ m}$ (מכונית א' מובילה ב-$40.00\text{ m}$).
  • ברגע $t = 58.00\text{ s}$: מכונית ב' מגיעה לקו הסיום ($x_B = 450.00\text{ m}$).
  • ברגע $t = 58.00\text{ s}$: מכונית א' טרם הגיעה לסיום ($x_A(58) = 450 - 2 \cdot 10 = 430.00\text{ m}$).
השאלה הנשאלת:

האם לאחר שיצאו המכוניות לדרכן ($t > 0$) היה רגע במהלך המרוץ שבו שתי המכוניות נמצאו באותו מרחק מנקודת המוצא? נמק.

קביעה חד-משמעית:

כן, היה רגע כזה במהלך המרוץ (מכונית ב' עקפה את מכונית א').

נימוק פיזיקלי ומתמטי מפורט (משפט ערך הביניים של הרציפות):
  • התנועה של שני הגופים היא רציפה בזמן, ולכן גם פונקציית המרחק היחסי $\Delta x(t) = x_B(t) - x_A(t)$ היא פונקציה רציפה.
  • ברגע $t = 30.00\text{ s}$, מצאנו בסעיף ג' כי מכונית ב' פיגרה אחרי מכונית א':
    $$x_B(30) - x_A(30) = 130.00\text{ m} - 170.00\text{ m} = -40.00\text{ m} < 0$$
  • לעומת זאת, נתון כי מכונית ב' חצתה את קו הסיום ($x = 450.00\text{ m}$) ברגע $t = 58.00\text{ s}$ (שתי שניות לפני מכונית א'). ברגע זה מכונית א' עדיין לא הגיעה לקו הסיום ($x_A(58) = 430.00\text{ m}$), ולכן:
    $$x_B(58) - x_A(58) = 450.00\text{ m} - 430.00\text{ m} = +20.00\text{ m} > 0$$
  • מכיוון שהפרש המיקומים החליף סימן משלילי לחיובי בקטע הזמן שבין $t = 30.00\text{ s}$ ל-$t = 58.00\text{ s}$, בהכרח היה רגע שבו ההפרש התאפס בדיוק ($\Delta x = 0 \implies x_B = x_A$).

ברגע זה שתי המכוניות היו בדיוק באותו מרחק מנקודת המוצא, ומכונית ב' חלפה על פני מכונית א' ועקפה אותה בדרכה לניצחון.

✓
כן. נימוק: ב-$t = 30.00\text{ s}$ מכונית ב' פיגרה אחרי מכונית א' ($130.00\text{ m} < 170.00\text{ m}$), אולם היא הקדימה אותה בסיום וחצתה את קו הסיום ב-$t = 58.00\text{ s}$ לפני מכונית א'. לכן בין $t = 30.00\text{ s}$ ל-$t = 58.00\text{ s}$ חל מפגש שבו שתיהן היו באותו מרחק מנקודת המוצא.

סעיף ה': חישוב תאוצת מכונית ב' בקטע האחרון של תנועתה

נתוני הקטע האחרון של מכונית ב':
  • תחילת הקטע: $t_0 = 30.00\text{ s}$, $x_0 = 130.00\text{ m}$, מהירות התחלתית $v_0 = 10.00\text{ m/s}$.
  • סיום הקטע בקו הסיום: $t_{\text{end}} = 58.00\text{ s}$, $x_{\text{end}} = 450.00\text{ m}$.
  • משך זמן הקטע האחרון: $\Delta t = 58.00 - 30.00 = 28.00\text{ s}$.
  • התאוצה $a$ בקטע זה קבועה.
השאלה הנשאלת:

חשב את תאוצת מכונית ב' בקטע האחרון של תנועתה (מ-$t = 30.00\text{ s}$ עד שהגיעה לקו הסיום). הנח שתאוצת המכונית בקטע זה קבועה.

נוסחאות דף עזר:
$\Delta x = v_0 \Delta t + \frac{1}{2} a (\Delta t)^2$
1. המרחק שעברה מכונית ב' בקטע זה ($\Delta x$):
$$\Delta x = x_{\text{finish}} - x_B(30) = 450.00\text{ m} - 130.00\text{ m} = 320.00\text{ m}$$
2. הצבה במשוואת המקום-זמן לתנועה שוות-תאוצה:
$$\Delta x = v_0 \cdot \Delta t + \frac{1}{2} a \cdot (\Delta t)^2$$ $$320.00 = 10.00 \cdot 28.00 + \frac{1}{2} a \cdot (28.00)^2$$ $$320.00 = 280.00 + \frac{1}{2} \cdot 784.00 \cdot a$$ $$320.00 = 280.00 + 392.00 \cdot a$$

בידוד התאוצה $a$:

$$392.00 \cdot a = 320.00 - 280.00 = 40.00$$ $$a = \frac{40.00}{392.00} = \frac{5}{49} \approx 0.102\text{ m/s}^2$$
3. חישוב מהירות הסיום של מכונית ב' (לבקרה פיזיקלית):
$$v_{\text{finish}} = v_0 + a \Delta t = 10.00 + \frac{40}{392} \cdot 28 = 10.00 + \frac{40}{14} = 10.00 + 2.857 = 12.86\text{ m/s}$$

מהירות זו עולה בקנה אחד עם שיפוע הגרף והערכים הפיזיקליים של התחרות.

✓
תאוצת מכונית ב' בקטע האחרון היא $a = 0.102\text{ m/s}^2$ (או במדויק: $\frac{5}{49}\text{ m/s}^2$).
