שאלה 1: קינמטיקה לאורך קו ישר

ניתוח גרף מהירות-זמן $v(t)$, קביעת תאוצה, כוחות שקולים, כיווני תנועה ועתקים

ניסוח השאלה והגרף המקורי

ברגע $t = 0\text{ s}$ גוף מתחיל לנוע ימינה לאורך קו ישר. הגרף שלפניך מתאר את מהירות הגוף כפונקציה של הזמן מ-$t = 0$ עד $t = 25\text{ s}$.

  1. סעיף א': האם הגוף משנה את כיוון תנועתו? אם לא – נמק. אם כן – ציין מתי, ונמק.
  2. סעיף ב': סרטט גרף המתאר את תאוצת הגוף כפונקציה של הזמן מרגע $t = 0$ עד רגע $t = 25\text{ s}$.
  3. סעיף ג': האם במהלך תנועתו הגוף חוזר לנקודת המוצא (הנקודה שממנה יצא ברגע $t = 0$)? אם כן – באיזה רגע; אם לא – נמק.
  4. סעיף ד': השלם בטבלה את כיוון המהירות, התאוצה והכוח השקול עבור פרק הזמן $0 < t < 5\text{ s}$.
  5. סעיף ה': השלם את שאר שורות הטבלה עבור כל פרקי הזמן השונים עד $t = 25\text{ s}$.
  6. סעיף ו': מהי תאוצת הגוף ברגע $t = 16\text{ s}$? נמק.
גרף $v(t)$ אינטראקטיבי (העבר סמן להפעלת לייזר עם עקבות של 2 שניות)

פתרון סעיף א': שינוי כיוון התנועה של הגוף

1. ניתוח פיזיקלי של כיוון התנועה

כיוון התנועה של גוף לאורך קו ישר נקבע באופן בלעדי על פי סימן המהירות הרגעית $v(t)$:

  • כאשר $v(t) > 0$: הגוף נע ימינה (הכיוון החיובי).
  • כאשר $v(t) < 0$: הגוף נע שמאלה (הכיוון השלילי).
  • כאשר $v(t) = 0$: הגוף נעצר רגעית ויכול לשנות את כיוון תנועתו אם סימן המהירות מתהפך.

2. מציאת רגע ההתאפסות וחציית ציר הזמן

בגרף הנתון, עבור הקטע שבין $t = 8\text{ s}$ ל-$t = 20\text{ s}$, הקו הישר עובר דרך הנקודות $(8, 10)$ ו-$(20, -5)$. נחשב את שיפוע הקו ($a$):

$$a = \frac{v_2 - v_1}{t_2 - t_1} = \frac{-5 - 10}{20 - 8} = \frac{-15}{12} = -1.25\text{ m/s}^2$$

משוואת המהירות בקטע זה הינה:

$$v(t) = 10 - 1.25 \cdot (t - 8) = 0 \implies 1.25 \cdot (t - 8) = 10 \implies t - 8 = 8 \implies t = 16.0\text{ s}$$

ברגע זה הגוף נעצר רגעית, ועובר ממהירות חיובית למהירות שלילית.

✓
תשובה: הגוף משנה את כיוון תנועתו ברגע $t = 16.0\text{ s}$.
נימוק: ברגע זה המהירות משנה את סימנה מערך חיובי ($v > 0$, תנועה ימינה) לערך שלילי ($v < 0$, תנועה שמאלה).

פתרון סעיף ב': סרטוט גרף תאוצה כפונקציה של הזמן $a(t)$

1. חישוב תאוצת הגוף בכל פרק זמן (שיפוע גרף $v-t$)

פרק זמן $0 < t < 5\text{ s}$ (תנועה שוות-תאוצה):

$$a_1 = \frac{10 - 0}{5 - 0} = +2.0\text{ m/s}^2$$

פרק זמן $5\text{ s} < t < 8\text{ s}$ (מהירות קבועה):

$$a_2 = \frac{10 - 10}{8 - 5} = 0.0\text{ m/s}^2$$

פרק זמן $8\text{ s} < t < 20\text{ s}$ (שיפוע קבוע ושלילי):

$$a_3 = \frac{-5 - 10}{20 - 8} = \frac{-15}{12} = -1.25\text{ m/s}^2$$

פרק זמן $20\text{ s} < t < 25\text{ s}$ (עלייה חזרה ל-0):

$$a_4 = \frac{0 - (-5)}{25 - 20} = \frac{5}{5} = +1.0\text{ m/s}^2$$
גרף תאוצה כפונקציה של הזמן $a(t)$
✓
סיכום ערכי התאוצה:
• עבור $0 < t < 5\text{ s}$: התאוצה היא $a = +2.0\text{ m/s}^2$
• עבור $5\text{ s} < t < 8\text{ s}$: התאוצה היא $a = 0.0\text{ m/s}^2$
• עבור $8\text{ s} < t < 20\text{ s}$: התאוצה היא $a = -1.25\text{ m/s}^2$
• עבור $20\text{ s} < t < 25\text{ s}$: התאוצה היא $a = +1.0\text{ m/s}^2$

פתרון סעיף ג': האם הגוף חוזר לנקודת המוצא?

1. משמעות גיאומטרית ופיזיקלית של חזרה לנקודת המוצא

נקודת המוצא של הגוף היא $x(0) = 0$. כדי שהגוף יחזור לנקודת המוצא, העתקו הכולל חייב להתאפס: $\Delta x = 0$.

ההעתק של הגוף מיוצג על ידי השטח הכלוא בין גרף המהירות לציר הזמן:

  • שטח מעל ציר הזמן ($v > 0$) מייצג העתק חיובי ימינה: $S_1 = \Delta x_{\text{right}}$.
  • שטח מתחת לציר הזמן ($v < 0$) מייצג העתק שלילי שמאלה: $S_2 = |\Delta x_{\text{left}}|$.

2. חישוב השטחים והעתקי התנועה

העתק ימינה ($0 \le t \le 16\text{ s}$ - שטח טרפז מעל הציר):

הבסיס התחתון הוא $16\text{ s}$, הבסיס העליון הוא $8 - 5 = 3\text{ s}$, והגובה הוא $10\text{ m/s}$:

$$\Delta x_{\text{right}} = S_{\text{trapezoid}} = \frac{16 + 3}{2} \cdot 10 = \frac{19}{2} \cdot 10 = 95.0\text{ m}$$

העתק שמאלה ($16\text{ s} \le t \le 25\text{ s}$ - שטח משולש מתחת לציר):

בסיס המשולש הוא $25 - 16 = 9\text{ s}$, וגובהו הוא $5\text{ m/s}$ (עומק המהירות המינימלית):

$$|\Delta x_{\text{left}}| = S_{\text{triangle}} = \frac{9 \cdot 5}{2} = 22.5\text{ m}$$

המיקום הסופי ברגע $t = 25\text{ s}$:

$$x(25) = x(0) + \Delta x_{\text{right}} - |\Delta x_{\text{left}}| = 0 + 95.0 - 22.5 = +72.5\text{ m}$$
✓
תשובה: הגוף אינו חוזר לנקודת המוצא.
נימוק: ב-16 השניות הראשונות הגוף עבר מרחק של $95.0\text{ m}$ ימינה, וב-9 השניות הבאות הוא נע שמאלה ועבר מרחק של $22.5\text{ m}$ בלבד (שטח הטרפז מעל ציר הזמן גדול משמעותית משטח המשולש שמתחתיו). ברגע $t = 25\text{ s}$ הגוף נמצא במיקום $x = +72.5\text{ m}$.

פתרון סעיפים ד'-ה': כיווני המהירות, התאוצה והכוח השקול

עקרונות קביעת כיווני הווקטורים:

  • כיוון המהירות: נקבע לפי סימן $v(t)$ (חיובי = ימינה, שלילי = שמאלה, 0 = אפס).
  • כיוון התאוצה: נקבע לפי שיפוע גרף $v-t$ (שיפוע עולה = ימינה, שיפוע יורד = שמאלה, שיפוע אופקי = אפס).
  • כיוון הכוח השקול ($\Sigma \vec{F}$): על פי החוק השני של ניוטון ($\Sigma \vec{F} = m\vec{a}$), כיוון הכוח השקול זהה תמיד לכיוון התאוצה.
פרק הזמן כיוון המהירות ($\vec{v}$) כיוון התאוצה ($\vec{a}$) כיוון הכוח השקול ($\Sigma \vec{F}$)
$0 < t < 5\text{ s}$ ימינה ימינה ימינה
$5\text{ s} < t < 8\text{ s}$ ימינה אפס אפס
$8\text{ s} < t < 16\text{ s}$ ימינה שמאלה שמאלה
$16\text{ s} < t < 20\text{ s}$ שמאלה שמאלה שמאלה
$20\text{ s} < t < 25\text{ s}$ שמאלה ימינה ימינה
✓
הערה: החלוקה ברגע $t = 16\text{ s}$ נדרשת מכיוון שכיוון וקטור המהירות מתהפך שם מימינה לשמאלה, למרות שכיוון התאוצה והכוח השקול נשארים שמאלה לאורך כל הקטע מ-$8\text{ s}$ ועד $20\text{ s}$.

פתרון סעיף ו': תאוצת הגוף ברגע $t = 16\text{ s}$

1. הגדרת התאוצה הרגעית

התאוצה ברגע נתון שווה לנגזרת המהירות לפי הזמן, שהיא שיפוע המשיק לגרף $v(t)$ באותו רגע.

ברגע $t = 16\text{ s}$, הגוף נמצא בתוך הקטע הרציף $8\text{ s} < t < 20\text{ s}$ שבו הגרף הוא קו ישר אחד בעל שיפוע קבוע.

2. חישוב שיפוע הקו הישר

$$a(16) = \frac{\Delta v}{\Delta t} = \frac{-5 - 10}{20 - 8} = \frac{-15}{12} = -1.25\text{ m/s}^2$$

אף על פי שמהירות הגוף ברגע זה שווה ל-0 ($v(16) = 0$), שיפוע הגרף אינו אפס אלא קבוע ושלילי לכל אורך הקטע.

✓
תשובה: תאוצת הגוף ברגע $t = 16\text{ s}$ היא $-1.25\text{ m/s}^2$ (או בגודל $1.25\text{ m/s}^2$ בכיוון שמאלה).
נימוק: התאוצה היא שיפוע גרף מהירות-זמן, ולאורך כל פרק הזמן מ-$8\text{ s}$ עד $20\text{ s}$ השיפוע קבוע ושווה ל-$-1.25\text{ m/s}^2$.
